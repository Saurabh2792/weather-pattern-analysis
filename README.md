# Weather Pattern Analysis

**Intern ID:** CITS8270

This project utilizes a machine learning classification model to predict rainfall based on temperature, humidity, and wind speed data.

## Project Structure
- `data/`: Raw dataset (`dataset.csv`)
- `notebooks/`: Exploratory analysis and logistic regression model training (`analysis.ipynb`)
- `src/`: Streamlit dashboard for real-time weather prediction (`app.py`)

## Tech Stack
- Python, Pandas, Matplotlib, Scikit-Learn, Streamlit
